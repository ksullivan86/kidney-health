Owner decisions (2026-10-31, devices):

* **Withings and Whoop: go.** The server signs in to each company with the person's consent and only fetches that person's
  own data; nothing about the person is sent out. Two releases: 0.16 = Connected devices groundwork + Withings (weight,
  blood pressure into the existing screens); 0.17 = Whoop (sleep, recovery, strain, HRV, workouts, calories burned), an
  Activity and recovery card in Trends, a Care team share area for it, and the active-day calorie extra.
* **Active-day extra (owner's choice, not an average):** calorie target = base (today's rule, inside KDOQI 25-35 kcal/kg)
  + what Whoop says was burned above the usual quiet-day level, updated through the day. Counts all of it by default; a
  per-person share (e.g. half) and an optional daily ceiling. Only calories rise: protein, potassium, phosphorus, sodium
  limits stay fixed. No insulin advice; one plain line on active days pointing to the care team; never block or warn
  against treating a low. HRV is shown, never acted on.
