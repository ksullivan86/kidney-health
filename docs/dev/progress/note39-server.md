Decisions:
* Kind value is `app_sync` (the note does not name it). Activity action `app.server_used`, label "The iPhone app read your data".
* The gateway refuses any Origin (stricter than other /push/v1 paths, as note §9 says) and any Sec-Fetch-Site but `none`.
* The gateway's caller has role `user` (dataclasses.replace) so nothing can treat it as admin.
* `account` = HMAC under keyring subkey; changes if SECRET_KEY is replaced (documented).
