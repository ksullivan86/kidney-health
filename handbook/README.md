# Kidney Health Handbook (`/learn`)

Practical, sourced guidance for living with chronic kidney disease and type 1 diabetes, for patients
and caregivers. The app serves the built site at `/learn/`; a public copy can be published to GitHub
Pages. Spec: `docs/dev/research/08-handbook-site.md`; contract: `ARCHITECTURE.md` (v0.3 items 11–12).

* **Text licence:** CC BY-NC-SA 4.0 (`LICENSE` in this folder). Code: PolyForm Noncommercial 1.0.0.
* **Every page is a draft** until a named clinician reviews it (`status: reviewed`, `reviewed_by`,
  `reviewed_on` in its front matter). No page gives insulin or medicine doses.

## Layout

```
mkdocs.yml            LAN build (site_url http://localhost/learn/); mkdocs.pages.yml = GitHub Pages build
requirements.in/.lock mkdocs 1.6.1, mkdocs-material 9.7.7, pymdown-extensions 12.1, PyYAML, pytest (hashed lock)
sources.yml           the bibliography: id -> cite, url, licence, checked date, kind
data/menus.yml        7-day sample menus by fdc_id + servings (checked against the app's targets)
data/slugs.yml        slugs the app links to (/learn/<path>/), read by app/guidance/topics.py
includes/             abbreviations (tooltips), the no-dosing box, the "starting points" box,
                      sources.md (GENERATED reference links appended to every page)
overrides/main.html   announce bar, draft banner, review line
templates/            page templates (medical and general) with the front-matter schema
docs/                 the pages; eat/menus/*.md, eat/grocery-lists.md, eat/_targets-table.md and
                      reference/sources.md are GENERATED by scripts/build_handbook.py
```

## Build

```bash
python3 -m venv .venv-hb && .venv-hb/bin/pip install --require-hashes -r handbook/requirements.lock
.venv-hb/bin/python scripts/build_handbook.py           # regenerate; --check in CI; --totals prints menu days
.venv-hb/bin/python -m pytest --noconftest tests/test_handbook_content.py
cd handbook && NO_MKDOCS_2_WARNING=true ../.venv-hb/bin/mkdocs build --strict
```

The full contributor guide (front matter, sources, safety lints, review flow) is the page
`docs/self-hosting/building-the-handbook.md`.
